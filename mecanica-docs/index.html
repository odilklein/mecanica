O que é este sistema

O Auto Mecânica Leme — Sistema de Gestão é um sistema interno de operação para uma oficina mecânica. Ele organiza o atendimento em uma cadeia única e simplificada:

A Ordem de Serviço (OS) é o centro do domínio: ela registra a queixa do cliente, o diagnóstico técnico, as tarefas, os funcionários responsáveis, as peças necessárias, o andamento e a entrega/retirada do veículo. Todos os demais registros se relacionam com a OS quando fazem parte de um atendimento.

Regra de ouro: a OS deve ser a fonte do andamento operacional. Não criar fluxos paralelos fora dessa cadeia.

Resumo do produto

4 áreas

clientes, funcionários, OS e pedidos de peças

4 perfis

admin, secretaria, mecânico-chefe e mecânico

12 status

ciclo completo da OS, de recebida a entregue

Áudio

tarefas podem ser anotadas por gravação de voz

Tecnologias utilizadas

PHP 8 + procedural

Código em PHP puro, sem framework, com PDO para acesso ao banco.

MySQL / MariaDB

Banco relacional com schema normalizado e chaves estrangeiras.

Bootstrap 5 + CSS próprio

Design system com tema claro/escuro em css/style.css.

Lucide Icons

Ícones carregados via CDN e usados em botões, menus e tabelas.

Não há framework PHP, Composer, API REST formal, camada de serviços separada nem ORM. Todo o acesso a dados usa prepared statements enviados pela conexão PDO global $conn.
