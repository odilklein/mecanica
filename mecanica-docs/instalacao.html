Instalação e ambiente

Como rodar o sistema localmente

Requisitos

XAMPP / WAMP

Apache + PHP 8.x + MySQL/MariaDB.

Navegador

Moderno (gravação de voz usa MediaRecorder).

Internet

CDNs de Bootstrap, Lucide, Google Fonts, Mermaid e highlight.js.

Passo a passo

  1. Inicie o Apache e o MySQL no XAMPP.
  2. Copie o projeto para a pasta do servidor: 
    C:\xampp\htdocs\mecanica
    (neste workspace: /mnt/e/New folder/htdocs/mecanica)
  3. Abra o phpMyAdmin (http://localhost/phpmyadmin).
  4. Em um banco vazio, importe sql/mecanica_teste.sql (recria o banco mecanica com dados de teste).
  5. Acesse http://localhost/mecanica/.
  6. Faça login com um usuário de teste (abaixo).

Configuração do banco

A conexão (config/conexao.php) lê variáveis de ambiente:

DB_HOST   (padrão: localhost)
DB_USER   (padrão: root)
DB_PASS   (padrão: vazio)
DB_NAME   (padrão: mecanica)
O arquivo .env da raiz não é carregado automaticamente pelo PHP. Escrever DB_USER=... ali não altera a aplicação sem configurar Apache/PHP para exportar essas variáveis. O .env é ignorado pelo Git e não deve receber segredos de produção.

Em um ambiente XAMPP padrão, os valores default já funcionam sem configuração.

Uploads (áudios)

  • Os áudios gravados nas tarefas são salvos em uploads/audio/.
  • A pasta é criada automaticamente na primeira gravação (o código usa mkdir recursivo em ordens_servico/processar.php).
  • Confirme que o Apache/PHP tem permissão de escrita na pasta uploads/. A pasta contém conteúdo gerado pelos usuários e não deve ser versionada no Git.
