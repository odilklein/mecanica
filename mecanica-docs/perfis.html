Perfis e permissões

Quem pode fazer o quê dentro do sistema

Os 4 perfis

Cada usuário possui exatamente um perfil, armazenado no campo usuarios.tipo. Os valores válidos são:

admin admin

Acesso administrativo completo, incluindo catálogo de peças e criação de outros admins.

secretaria secretaria

Clientes, veículos, funcionários, OS, pedidos de peças (valida, compra e recebe), orçamentos e catálogo.

mecanico_chefe mecânico-chefe

Supervisiona: cria OS, designa funcionários, valida solicitações, acompanha a operação e faz diagnóstico.

mecanico mecânico

Vê apenas as OS atribuídas a ele, atualiza tarefas/diagnóstico e solicita peças das próprias OS.

A documentação desta pasta mecanica-docs é um site separado do sistema: não exige login e não depende de perfil para ser lida.
Ocultar um item no menu não é controle de segurança. Toda página protegida também bloqueia acesso direto por URL no backend.

Tela "Meus dados"

  • Cada usuário edita o próprio nome, e-mail e senha.
    O perfil (tipo) não pode ser alterado pelo próprio usuário.
  • Novos dados de contato ficam ao critério do completo cadastro (CPF/telefone) — a página atual altera apenas nome/e-mail/senha.
  • A nova senha exige no mínimo 8 caracteres e confirmação igual; a atual (antiga) não é exigida no momento.

Filtro obrigatório do mecânico

Toda listagem, detalhe, dashboard e pedido de um mecânico deve filtrar por vínculo ativo:

os_responsaveis.usuario_id = :logado
AND os_responsaveis.concluido_em IS NULL
Não remover esse filtro — é o que impede um mecânico de ver dados de OS que não são dele.

Exemplo no código

// autenticação e CSRF
require sessao.php, conexao.php
validar_csrf();

// autorização no backend
exigir_papel(['admin','secretaria']);

// autorização condicional
if (tem_papel(['admin','mecanico_chefe'])) {
    // designar mecânico
}
